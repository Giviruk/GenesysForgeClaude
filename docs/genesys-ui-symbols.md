# Символы и русские термины Genesys в интерфейсе

План: [genesys-original-symbols.md](../roadmap/tasks/genesys-original-symbols.md).
Изменение выполняет запрос владельца от 12.10.2026 о формах игровых символов и
дополнение о названиях из русской основной книги.

## Шрифт и отображение

Используется локальный WOFF2 **Genesys Glyphs and Dice**, 4,268 байт, из
[репозитория авторов](https://github.com/themensch/FFG-Genesys-Glyphs-and-Dice),
commit `08b75a17a2c30183396f757dc6ba575d1d267960`.
Это шрифт сообщества; upstream не заявляет одобрения FFG/Edge.
MIT-лицензия сохранена в исходниках и включена в deployment по адресу
`/third-party/genesys-font-LICENSE.txt`.

Общий `GenesysSymbol` рисует шесть видов костей и шесть результатов, используя
контуры шрифта. Каждый значок имеет доступную подпись на языке интерфейса;
декоративный вариант не дублирует подпись кнопки. Шрифт применяется только к самому
глифу, поэтому слова и числа остаются обычным текстом.

Обновлены наборы костей на листах/NPC, дайсроллер и результаты броска, подсказки
трат, ремесло, сложность магии, легенда листа и печатные карточки. Тексты талантов,
героики, свойств оружия и способностей NPC используют общий рендерер.
Старые Unicode-заменители и PUA-символы результатов поддерживаются при отображении.
Сохранённые тексты и JSON бросков не переписываются. Символы `@`/`*` внутри адресов
и слов с Markdown-разметкой не принимаются за старые OCR-значки.

## Русская терминология

Источник — локальный gitignored `_books/Genesys Corebook RUS - Vector.pdf`:
с. 9–13 (кости/результаты), 13–15 (характеристики), 18 (сложности),
таблица I.3-1 на с. 53 (навыки), с. 106–107 (дистанции), с. 131–133 (противники).
Страницы с изображениями просмотрены после рендеринга. PDF и оригинальные
описания правил в репозиторий не добавлены.

Базовые подписи собраны в `frontend/src/data/coreTerminology.ts`:

| Английский ключ | Русская подпись |
|---|---|
| Brawn / Cunning | Сила / Смекалка |
| Boost / Setback | Кость бонуса / Кость штрафа |
| Threat / Despair | Осложнение / Крах |
| Minion / Rival / Nemesis | Приспешник / Соперник / Главарь |
| Engaged / Short / Medium / Long / Extreme | Вплотную / Короткая / Средняя / Длинная / Экстремальная |
| Difficulty 0–5 | Элементарная, Лёгкая, Обычная, Сложная, Пугающая, Запредельная |
| Discipline / Operating / Perception | Выдержка / Управление / Внимание |
| Resilience / Skulduggery / Streetwise | Стойкость / Жульничество / Уличная интуиция |
| Brawl / Gunnery / Coercion | Грубая сила / Артиллерия / Запугивание |
| Arcana / Divine / Primal | Магия / Вера / Природа |
| Melee/Ranged (Light/Heavy) | Ближний/Дальний бой (лёгкое/тяжёлое оружие) |

Магические навыки Runes/Verse и прочий специфичный RoT-контент не переводятся
по догадке из Core. Указанные изменения относятся к общим терминам, которые есть
в основной книге. «Отчаяние» как название дополнительного эффекта заклинания
отличается от символа Despair; оно не заменено глобально на «Крах».

## Совместимость

`SkillDef.NameRu` встроенных навыков обновляется существующим seed по стабильному
Code. Ранее созданные строки получают новые подписи без замены ID. Проверка
`OwnerUserId == null` сохраняет пользовательские определения.

`Name`, enum/JSON-ключи, IDs, ранги и формулы не меняются. Сохранённые NPC-навыки
со старыми русскими названиями распознаются через алиасы. Точное имя пользовательского
навыка имеет приоритет перед таким алиасом. NPC показывает имя навыка из справочника
в текущей локали, сохраняя ранги из своего профиля. Печатная карточка и её
Markdown-экспорт используют тот же справочник и алиасы.

Возврат приспешников при уменьшении ран оставлен по решению владельца.
Миграция, обновление версий пакетов, установка зависимостей и изменения API-контрактов
не потребовались. Обычный запуск приложения применит существующий seed для новых
названий; этот PR сам по себе не развёртывает приложение.
