## Проверки

- `npm run lint` — успешно.
- `npm test -- --run` — 81 файл, 669 тестов успешно.
- После финальной правки переноса имени в обзоре — все 19 тестов `CampaignsPage` успешно.
- `npm run build` — успешно; production frontend использован в браузерной приёмке.
- Playwright: `layout`, `bestiary`, `v5-stack-review`, `campaign-sheet-navigation`, `redesign-followup` — 45 сценариев успешно.
- После финального уменьшения подписей счётчиков предпросмотра повторно проверены оба RU/EN сценария NPC/магазина/справочника/создания персонажа — 2/2 успешно.
- Новые визуальные сценарии проверяют 375, 768, 1024, 1240 и 1440 px; существующие регрессии дополнительно покрывают 320, 390, 1280 px, печать и промежуточные ширины.
- Проверены отсутствие горизонтального переполнения, пересечений элементов, положение заголовков, центрирование иконок, клавиатурное открытие листов и удаление участников.
- Добавлены модульные регрессии отключённой усталости и `null` при сохранении соперника/приспешника, редактируемой усталости немезиды и расположения талантов.

Браузерные проверки запущены с установленным Google Chrome через `E2E_CHROMIUM_EXECUTABLE`.
Макеты и фактические экраны дополнительно сверены вручную в браузере.

## Границы изменений

Изменения ограничены frontend, его проверками и документацией. Миграций нет.
Серверные игровые правила, XP, расчёт цен, схема БД и публичный контракт API не менялись.
Формы сохраняют существующие операции; удалены только явно перечисленные владельцем блоки.
CSS правки ограничены экранным отображением, существующая регрессия печатной палитры прошла.
Оригинальные тексты официальных книг и новые seed-данные не добавлялись.
Пользовательские незакоммиченные файлы основного checkout не изменялись.
