## Границы изменений

Первоначальная визуальная приёмка ограничивалась frontend. По ревью добавлена серверная
нормализация усталости NPC и миграция очистки старых значений (см. ниже).
XP, расчёт цен, схема БД и публичный контракт API не менялись.
Формы сохраняют существующие операции; удалены только явно перечисленные владельцем блоки.
CSS правки ограничены экранным отображением, существующая регрессия печатной палитры прошла.
Оригинальные тексты официальных книг и новые seed-данные не добавлялись.
Пользовательские незакоммиченные файлы основного checkout не изменялись.

## Исправления ревью PR #295

Исправлены 13 инлайн-замечаний и два пункта общего ревью от 14.10.2026:

- Сетка с колонкой иконки применяется только к редактируемым карточкам с `.inv-item-icon`;
  просмотр инвентаря кампании проверяется с повреждённым предметом на desktop/mobile.
- Активации способностей с пустым результатом не получают «Провал». Старые броски
  показывают дату и время; сегодняшние — время. Строки журнала допускают перенос.
- Enter/Space открывают участника только при фокусе самой карточки. Вложенные кнопки,
  чекбоксы и броски выполняют свои действия; локальный обработчик крестика больше не нужен.
- Галочки заполненности NPC учитывают таланты в «Способностях». Индекс навыков
  мемоизируется и передаётся в сводку, включая быстрый черновик.
- Подавление синего фокуса ограничено мотивациями и предысторией. Поле заметки сохраняет
  видимый контур 2 px при клавиатурной навигации. Мобильные крестики и фишки оплаты — 44 px.
- Оплаченный символ отмечен `aria-pressed`, включая отключённую неповторяемую трату.
  «Успехи» сохраняют указанное владельцем название и получили доступную подсказку о
  вычитании провалов. Пустые секции трат не выводятся.
- Блок GEN-V5-13 перенесён к исходным правилам соответствующих компонентов. Убраны
  лишние повышающие специфичность селекторы, повторные сетки стола и абсолютное положение
  крестиков. Мёртвые стили `ring-focus-switch`, `qd-preview-card`, `heroic-summary` удалены.
- E2E больше не записывает учётные данные в общий `/tmp`; ранее созданный тестовый файл удалён.
- Сервер нормализует порог усталости при create/update/read/copy NPC и при добавлении/правке
  участника стола. Только немезида сохраняет порог; ручные одиночные участники и PC не затронуты.
- `20261014100143_NormalizeNpcStrain` очищает старые пороги соперников/приспешников и усталость
  их участников сцены/групп. Схема и сущности сохраняются; `Down` не возвращает ошибочные значения.
- Материал и количество магазина используют общие строки сетки, поэтому перенос подписи
  не сдвигает поля. Геометрические проверки E2E ждут загрузки шрифтов.

Регрессии: 675 Vitest, 773 Domain, 959 API и обе PostgreSQL migration-проверки (Up/Down).
PostgreSQL-проверки повторно выполнены по отдельности после конфликтов очистки БД при
одновременной нагрузке; оба отдельных прогона прошли. Lint/build успешны, EF подтвердил
отсутствие pending model changes. Все 45 браузерных сценариев прошли; проверка включает RU/EN, read-only инвентарь,
клавиатурный фокус заметок, вложенные действия и размеры мобильных кнопок.
