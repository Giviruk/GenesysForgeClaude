Исправления внесены в исходные ветки соответствующих PR и объединены снизу вверх
через merge-коммиты, без force-push. Итоговая ветка —
`feature/gen-v5-11-other-screens` ([PR #292](https://github.com/Giviruk/GenesysForgeClaude/pull/292)).
Новых PR не требуется; существующие планы обновляются в тех же ветках.

Бизнес-логика, API, auth, schema, seed, зависимости и печатные React-шаблоны
не менялись. Поведение клонирования сохранено: после создания копии открывается
её лист. Печатный CSS оболочки/строк навыков изменён для исправления Ctrl+P;
палитра символов, восстановленная в #293, сохранена.
