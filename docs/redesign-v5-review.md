# Исправления ревью редизайна v5

13.10.2026, [PR #293](https://github.com/Giviruk/GenesysForgeClaude/pull/293).
Продолжение [GEN-V5-12](../roadmap/tasks/gen-v5-12-cleanup-qa.md); все изменения
остаются в ветке `feature/gen-v5-12-cleanup-qa`.

| Замечание | Исправление |
|---|---|
| R1: пересечение кириллицы Fira | Во всех четырёх весах cyrillic объявляет обычные буквы U+0400–045F, ext — только U+0460–052F / U+1C80–1C88 и комбинирующие знаки. Обычный русский заголовок больше не загружает ext и не собирается из двух font faces. |
| R2: таблицы и тёмные разделители | Экранное правило `table.ref-table td` имеет нужную специфичность; старые rgba-разделители заменены на `--line-soft` в справочнике, навыках, описаниях эффектов, контенте и журнале. |
| R3: стол на планшете | Удалён устаревший 78rem-блок стола. На 769–1100px центральная область занимает всю ширину, две вертикальные колонки панелей находятся ниже; участники — в отдельной четвёртой строке. Это исключает неявные колонки от auto-placement. Нерелевантный breakpoint редактора NPC сохранён. |
| R4: дробные размеры | Десктопное правило использует `(width > 1100px)`, дополняя `(max-width:1100px)` без разрыва. Проверен CSS viewport 1100.5px в iframe. |
| R5: карточки кампаний | Компактная мобильная сетка ограничена `.characters-page .char-card:not(.skeleton-card)`. Имя, роль и число персонажей кампании занимают полную ширину. |
| R6: цвета на бумаге | Отдельный `@media print` восстанавливает цвета всех шести результатов и костей из master. На экране остаётся палитра v5. Печатные React-компоненты и существующие print-блоки не изменены. Новые глобальные текстовые шрифты по-прежнему наследуются печатными компонентами; поэтому совпадение всей типографики с master не заявляется. |
| R7: клавиатура/a11y | Accessible name карточки кампании включает имя, роль и число персонажей. Обработчик Enter/Space вынесен в `activateLinkOnKey`, события вложенных кнопок не перехватываются. |
| R8: активации | `activationKey` нормализует RU/EN-метаданные; тон выбирается одним lookup из каталога. Та же нормализация используется для пассивных талантов. |
| R9: fonts.css | Пустые комментарии удалены; подписи отражают раздельные подмножества и отдельный Jost для бренда. |
| R10: редкость | Неизвестная редкость получает `rarity-unknown`; span наследует тон строки. Недостижимый fallback удалён, обычный разделитель вынесен из цветного текста. Цена и расчёты материалов не изменены. |
| R11: легенда | Легенда рангов использует `.rd-rank-diamonds > i.filled`, как реальные навыки. Регрессия покупки/refund проверяет ромбы строки навыка отдельно от декоративной легенды. |
| R12: favicon | Favicon использует тот же SVG GenesysForge, что и PWA, вместо иконки Vite. |

Пять новых браузерных регрессий проверяют загрузку кириллицы, реальную
специфичность/отступы таблиц, mobile/a11y кампаний, ширину всех блоков стола и
print-палитру. У стола дополнительно проверяются число колонок, минимальная ширина
панелей и заполнение всей строки центральной областью, командной панелью и
участниками: одного отсутствия overflow недостаточно.

Unit-регрессии покрывают нормализацию RU/EN-активаций, Enter/Space и события
вложенных контролов, нейтральную неизвестную редкость. Backend, правила, API,
schema, seed и зависимости не менялись.
