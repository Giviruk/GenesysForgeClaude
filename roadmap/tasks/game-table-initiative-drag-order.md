## Контекст

На игровом столе мастер уже может добавлять, удалять и редактировать слоты инициативы, а API поддерживает поле `order`. Нужно добавить ручное перетаскивание строк инициативы с сохранением порядка и не менять текущий активный слот при перестановке.
