## Контекст

Сейчас SignalR рассылает событие `GameTableChanged`, но позиции токенов на поле дистанций живут только в `localStorage` браузера. Поэтому другой клиент не может увидеть перемещение. Скрытие участника уже сохраняется на сервере и должно обновляться тем же realtime-каналом. Основные файлы: SignalR hook, Game Table, DTO/handler участника, EF-модель и CORS-конфигурация.

## Заметки / решения

- Assumption: позиция токена должна сохраняться между перезагрузками и быть общей для участников одной активной сцены, поэтому она добавляется к `GameParticipant`, а не передаётся только эфемерным SignalR-событием.
- Угол хранится как число градусов, зона — как ограниченная строка из пяти UI-зон; старые участники без позиции используют прежние значения по умолчанию.
- Скрытость остаётся серверным ACL-поведением: GM видит скрытых участников, игроки получают их только после снятия флага.
