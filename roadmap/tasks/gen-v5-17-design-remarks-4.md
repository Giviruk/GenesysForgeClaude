## Заметки / решения

- G-05: сервер хранит в проекте снимок `ItemDef.Name`; клиент ищет запись по `itemDefId`, для своих предметов без записи остаётся снимок. API не меняется.
- G-08: «применимы к атакам» — качества с категорией «Оружие…» (25 из 80 записей справочника; остальное — эффекты заклинаний).
- G-09: `useTooltipPosition` ставит тултип `position:fixed` у тега и переворачивает его над тегом, если снизу нет места; учёт обрезающих предков больше не нужен.
