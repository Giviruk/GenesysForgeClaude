## Контекст

Обычные Unicode-замены в пулах, роллере и описаниях правил нужно заменить формами
символов Genesys. Текущие шрифты Cinzel/Spectral не содержат игровые глифы.
Источник: [Genesys Glyphs and Dice](https://github.com/themensch/FFG-Genesys-Glyphs-and-Dice),
webfont и MIT LICENSE, commit `08b75a17a2c30183396f757dc6ba575d1d267960`.
Это шрифт сообщества; README не заявляет одобрения FFG/Edge. Не называть его
официальным шрифтом издателя. Шрифт текста интерфейса не относится к этому изменению.

## Заметки / решения

- Символы добавляются на уровне отображения: сохранённые описания, JSON результатов
  и правила расчёта кубиков не меняются.
- Отдельные глифы используют специальный font-family; русские/английские слова,
  числа и знаки операций остаются обычным текстом с доступными подписями.
- Возврат миньонов при уменьшении ран сохранён по предыдущему решению владельца.
- Дополнение владельца: привести нейминг и локализацию к русской основной книге.
  Источник — локальный `_books/Genesys Corebook RUS - Vector.pdf`, с. 9–19, 53,
  106–107, 131–134. Seed меняет только `NameRu` встроенных навыков; английские ключи и ID
  сохраняются, пользовательские записи seed не трогает.
- Финальные проверки после исправления печати: build и ESLint проходят; весь Vitest —
  628/628, Playwright — 6/6. Целевые xUnit — 58/58: SeedDataTests 19, NpcTests 31,
