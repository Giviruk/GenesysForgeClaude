## Контекст

После исправления drag-and-drop в PR #180 предварительный маркер сразу защёлкивается в центр
кольцевой ячейки. При пересечении границы диапазона он визуально скачет между кольцами. Нужно
двигать маркер непрерывно под курсором, сохранив защёлкивание в свободную ячейку при отпускании.
