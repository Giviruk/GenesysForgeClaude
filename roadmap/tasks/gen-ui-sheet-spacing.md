## Заметки / решения

- Ревью: общий `.icon-text` отделяет иконку от обычного текста, сохраняя переносы и inline-разметку; `:where(...)` задаёт минимальный gap кнопок и сохраняет специфичные отступы меню.
- Стили героики собраны в одном блоке. Старый fixture GEN-UI-01 восстановлен; для новых проверок созданы отдельные персонажи/кампания с перегрузом, повреждённым улучшением, выведенным из строя транспортом, пустой способностью и названием без пробелов длиной 120 символов.
- E2E: один тест на ширину с RU/EN; между маршрутами используется History API вместо полной загрузки документа. Смена языка по существующему UI требует одной перезагрузки из-за словарей, вычисляемых при загрузке.
- Меняется только представление frontend; API, правила игры, persistent model, seed и зависимости не меняются.
- Copyright: новые тексты из книг не добавляются.
- Исправлены: поля и кнопки личности способности, заголовки с иконками, вложенные вторичные эффекты, купленные улучшения в кратком блоке, форма именного оружия, строки игроков и открытые формы кампании, метки перегруза инвентаря, пояснение транспорта и метка системы перед категориями редактора контента.
- Дополнительно осмотрены таланты, магия, ремесло, улучшения, образ/заметки, игровой стол, контент кампании, библиотека, профиль, бестиарий и справочник. Компактные переключатели и прозрачные строки навигации имеют намеренно общий контур/область; их геометрия не менялась.
- E2E воспроизводит купленные Power/Duration/Frequency/Story/Secondary upgrades, незаполненную форму именного оружия, перегруз и несколько игроков с длинными именами. Проверяются реальные расстояния элементов, обе локализации и пять ширин, а также краткий блок в листе участника кампании.
- Проверки после ревью: lint/build прошли; полный Vitest — 73 файла / 602 теста, включая два сценария пробелов в копируемом тексте инвентаря. Полный Chromium E2E в локальном PrivateFull — 24 passed / 4 skipped (PublicSafe и deployment-only проверки), 3 минуты. Количество тестов уменьшилось на пять за счёт объединения RU/EN; проверки всех пяти ширин сохранены и дополнены.
- E2E проверяет отступы в заметках/образе, ремесле, улучшениях и магии, gap 8 px в меню листа, яркость купленных эффектов и неизменную высоту панели игроков под модалкой. Каждый сценарий RU/EN выполняет ровно две загрузки документа. Снимок героики RU/1280 px визуально проверен.
