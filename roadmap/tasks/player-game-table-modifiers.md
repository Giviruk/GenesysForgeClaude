# Бусты и сетбеки собственного персонажа на игровом столе (player-game-table-modifiers)

- **Пункт ТЗ:** GEN — игроки управляют временными модификаторами своего персонажа на Game Table
- **Ветка:** `feature/player-game-table-modifiers`
- **Базовая ветка:** `master`
- **PR:** #208
- **Статус:** 🚧 In progress

## Контекст

Счётчики `boostDice` и `setbackDice` уже сохраняются в участнике сцены и изменяются мастером. Нужно разрешить игроку менять эти значения только у собственного персонажа, когда мастер включил редактирование состояния игроков. NPC и чужие персонажи остаются недоступны игроку.
