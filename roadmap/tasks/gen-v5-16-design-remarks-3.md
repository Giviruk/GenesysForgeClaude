## Заметки / решения

- «Быстрые действия» убраны по указанию владельца. Чтобы не потерять добавление участника в идущую сцену, форма открывается кнопкой «+ Участник» в шапке «Участники сцены»; отдельный выбор «участник для удаления» не нужен — «✕» есть на карточке.
- «Курсив» заголовков — оптический эффект диагональной штриховки 118°: глифы прямые. Штриховка стала горизонтальной.
- Кнопка рядом с селектом получает высоту селекта общим правилом в `Select.css` с нулевой специфичностью: явные размеры контекстов (строки магазина, инициатива) сильнее.
- Локальный Playwright против `vite dev` даёт ложное падение (StrictMode дважды запрашивает список NPC); CI и локальная проверка — на production-сборке.
- Кольца дистанций: границы `12.7 / 25.4 / 35.2 / 42.1 / 49 %`, полосы 12.7 / 12.7 / 9.8 / 6.9 / 6.9 — длинная и экстремальная на 30 % уже средней.
