- **Ветка:** `feature/craftable-inventory-catalog`
- **Базовая ветка:** `master`

- **Статус:** ✅ Implementation complete; draft PR open, awaiting CI/review

## Контекст

Вкладка «Ремесло» считала любой предмет с ценой и редкостью доступным для изготовления. Из-за
этого в список попадали услуги и готовая еда из общей витрины, например `meal-tavern`. Кроме того,
общая запись `revolver` ошибочно разворачивалась и в каталог Realms of Terrinoth.

## Заметки / решения

- Услуги определяются существующим `ShopCatalogRules.IsService` по stable code, а не по названию.
- Custom item с совпадающим отображаемым именем не блокируется.
- Револьвер остаётся активным в Genesys Core; RoT-копия получает `Retired=true`, а не удаляется.
