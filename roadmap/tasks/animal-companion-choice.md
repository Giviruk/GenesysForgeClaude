## Контекст

Backend требует один непустой `AnimalCompanion` choice для каждого ранга таланта, но
`TalentsTab` открывает выбор только для Dedication. Нажатие «Купить» поэтому отправляет пустой
`choices` и получает `talent.choice.required` без возможности исправить запрос.

## Заметки / решения

- Спутник выбирается из доступной игроку библиотеки NPC; сохраняется стабильный NPC id и снимок
  имени. Backend повторно проверяет видимость, систему, тег животного и предел силуэта текущего ранга.
- Животными считаются NPC с точным тегом `animal`, `животное` или `зверь` без учёта регистра.
  Тег `зверь` уже добавляется существующим шаблоном NPC «Зверь».
- `NpcListItem` аддитивно получил `silhouette`; схема БД не меняется, миграция не нужна.
- Проверки: backend 740 domain + 842 API; frontend 315 тестов, lint и production build.
- Модель данных и миграция не меняются: `CharacterTalentChoices` уже хранит выбор по рангу.
