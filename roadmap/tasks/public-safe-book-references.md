## Контекст

Пользователь поручил довести PublicSafe до полноценной безопасной публичной версии. Для встроенных талантов и героических способностей явно выбран формат: только название и ссылка на книгу с печатной страницей, без описаний RU/EN. Игровые параметры и правила расчётов сохраняются, PrivateFull сохраняет описания. Пользовательский контент остаётся собственностью автора и не подменяется seed.

## Заметки / решения

- Номера — печатные страницы книг, не индексы PDF. PDF и извлечённый текст не коммитятся.
- Развёртывание и merge в эту задачу не входят; результат — код, проверки и PR.

- Сверены 120/123 таланта; три legacy-источника не подтверждены, задан вопрос владельцу. Для Core явно указана пагинация RU translation.
- Backend/PublicArtifact/Chromium проверки проходят; итоговые результаты и ограничения — [public-safe-release.md](../../docs/public-safe-release.md).
- `Assumption`: до ответа сохраняем три legacy-записи с явной отметкой; не меняем их правила/видимость самостоятельно.

- Разрешено и выполнено npm ci, lock-файл не менялся; lint/build/456 tests прошли. Все 8 E2E прошли с Playwright 1.63.0 и имеющимся Chromium 1228; macOS 13 не поддерживает штатный Chromium новой версии, CI использует Linux.
- CI commit 008d370 полностью прошёл: backend/frontend, обе PostgreSQL 17 migration jobs и оба Docker E2E jobs ([run](https://github.com/Giviruk/GenesysForgeClaude/actions/runs/37377173867)).
