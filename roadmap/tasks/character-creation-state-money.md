# Исправить состояние выбора карьеры и отображение стартовых денег

## Цель

Исправить два пользовательских сценария создания персонажа: смена карьеры должна очищать
выбранные бесплатные карьерные навыки, а стандартные стартовые деньги должны быть обычным
балансом 500 монет без отдельного бюджета покупок.

## План

- [x] Проверить текущую логику формы создания и отображения денег.
- [x] Сбрасывать устаревшие навыковые выборы при смене карьеры и добавить регрессионные тесты.
- [x] Показать единый баланс стандартных денег в панели инвентаря и покрыть сценарий тестом.
- [x] Запустить полный набор проверок, обновить этот план и оформить PR.

## Решение и проверки

Клиентская форма и сервер используют единый кошелёк: стандартный режим выдаёт 500 монет,
а карьерный комплект сохраняет свои формулы и позиции. Отдельного бюджета больше нет.

Проверки: `npm test` (50 файлов, 407 тестов), `npm run build`, `npm run lint`,
`dotnet test` для Domain и API (857 API-тестов).
