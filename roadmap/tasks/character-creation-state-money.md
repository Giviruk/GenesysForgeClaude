# Исправить состояние выбора карьеры и отображение стартовых денег

## Цель

Исправить два пользовательских сценария создания персонажа: смена карьеры должна очищать
выбранные бесплатные карьерные навыки, а инвентарь должен явно показывать бюджет стартовых
покупок 500 серебра при режиме стандартных денег, не скрывая отдельные карманные деньги.

- [x] Сбрасывать устаревшие навыковые выборы при смене карьеры и добавить регрессионные тесты.
- [x] Показать бюджет создания в панели денег инвентаря и покрыть сценарий тестом.
- [x] Запустить полный набор проверок, обновить этот план и оформить PR.

## Решение и проверки

Будут изменены только клиентская форма создания и отображение панели денег. Раздельные счета
кошелька и бюджета сохраняются: бюджет используется для стартовых покупок, а карманные деньги
остаются реальным балансом персонажа.

Проверки: `npm test` (50 файлов, 407 тестов), `npm run build`, `npm run lint`,
`dotnet test` для Domain и API (857 API-тестов).
