## Заметки / решения

- Scope ограничен `.game-table`; общие страницы и компоненты не затрагиваются.
- Пользовательские файлы `UI макет игрового стола*`, `CLAUDE.md` и `.claude/settings.json`
  остаются неотслеживаемыми.
- Удалена принудительная высота средней строки grid (`34rem`), создававшая отмеченную на макете
  пустую полосу перед карточками участников.
- Отступы игрового стола изолированы от глобального `margin` панели; выровнены размеры кругов,
  токенов, инициативы, карточек, правой колонки и управляющих элементов по секции `1b`.
- Правая колонка приведена к порядку макета: броски → быстрые действия → заметки.
- Проверки: `npm run lint`; 8 целевых Vitest-тестов игрового стола; полный frontend Vitest;
  `npm run build`; `git diff --check`.
