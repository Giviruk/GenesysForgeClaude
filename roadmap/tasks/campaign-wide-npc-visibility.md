# Общая видимость NPC во всех кампаниях мастера (campaign-wide-npc-visibility)

- **Пункт ТЗ:** GEN-NPC-VISIBILITY — один кампанийный NPC для всех кампаний мастера
- **Ветка:** `feature/campaign-wide-npc-visibility`
- **Базовая ветка:** `feature/chronicle-npc-combobox` (stacked PR #194)
- **PR:** #195
- **Статус:** ✅ Реализация завершена, draft PR открыт

## Контекст

Видимость `campaignVisible` не должна требовать выбора одной кампании. Такой NPC должен быть доступен участникам всех кампаний, в которых владелец NPC является мастером, и появляться в кампанийных селекторах этих кампаний.
