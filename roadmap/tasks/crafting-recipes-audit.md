## Контекст

После появления вкладки «Ремесло» один список каталога использовался и для обычного изготовления,
и для варки. Backend также не проверял соответствие `CraftingKind` выбранной записи. Базовые навыки
и формулы цен совпадают с ТЗ, но зачарование в UI не позволяло выбрать подходящий магический навык.

## Результат аудита

- Навыки: Mechanics для обычного изготовления, Survival для грубой работы и Alchemy для варки
  совпадали; зачарование исправлено с неявного Arcana на выбор видимого магического навыка.
- Цены и редкость всех 12 алхимических расходников совпали с ROT-ALCH-01.
- Component cost для каждого рецепта подтверждён как `ceil(price / 2)`; формула не менялась.
