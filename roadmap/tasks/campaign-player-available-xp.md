# Доступный XP игрока на обзоре кампании (campaign-player-available-xp)

- **Пункт ТЗ:** UI-кампании — показывать владельцу доступный XP на обзоре
- **Ветка:** `feature/campaign-player-available-xp`
- **Базовая ветка:** `master`
- **PR:** [#226](https://github.com/Giviruk/GenesysForgeClaude/pull/226)
- **Статус:** 🚧 In progress

## Контекст

На обзоре кампании полные листы участников загружаются только мастером. Поэтому карточка собственного персонажа игрока не получает `availableXp` и показывает «—». Добавляем в DTO кампании доступный XP только для владельца соответствующего персонажа и используем его в карточке.
