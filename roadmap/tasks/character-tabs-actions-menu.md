## Контекст

На странице персонажа нужно поставить первыми часто используемые вкладки: Лист, Инвентарь,
Таланты, Магия, Заметки. Печать, клонирование, публичную ссылку, отзыв ссылок и экспорт JSON
нужно убрать из шапки в меню под кнопкой с тремя точками.

## Заметки / решения

- Задача выполняется от свежего `master`; открытых PR на момент старта нет.
- Бизнес-логика действий и формат API не меняются — меняется только их размещение.
- Порядок вкладок: Лист, Инвентарь, Таланты, Магия, Заметки; затем Героика (ROT), Улучшения,
  Транспорт, Ремесло, Образ, История и Кастом.
- Меню получает доступные атрибуты `aria-haspopup`, `aria-expanded`, `role=menu/menuitem`,
  закрывается после выбора, по Escape и при клике вне него.
- На ширине 600 px меню занимает 224 px и остаётся внутри экрана.
- Проверки: ESLint; целевой SheetPage Vitest — 8 тестов; полный frontend Vitest — 338 тестов;
  production build; интерактивная браузерная проверка; `git diff --check`.
- Persistent model, API, seed и справочники не менялись; миграция и copyright-изменения не нужны.
- Задача отсутствует в ROT remediation, поэтому общий ROT progress не менялся.
