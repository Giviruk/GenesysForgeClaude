## Контекст

Общий магазин не показывает боевые характеристики предметов. Магазин внутри инвентаря берёт
урон только из старого строкового поля и теряет значение оружия со структурным профилем атаки;
поглощение брони в строке также отсутствует.

## Заметки / решения

- Для оружия используется основной структурный `attackProfile`; строковые `damage`/`crit`
  остаются fallback для старого и пользовательского контента.
- Для всей брони характеристика показывается явно, включая `Поглощение +0`.
- Backend, API и схема БД не меняются; миграция не нужна.
- Проверки: frontend 319 тестов, lint и production build.
