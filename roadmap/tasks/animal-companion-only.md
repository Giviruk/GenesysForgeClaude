## Заметки / решения

- Животными считаются NPC с точным тегом `animal`, `животное` или `зверь` без учёта регистра.
- Тег `зверь` уже добавляется существующим шаблоном NPC «Зверь».
- Название NPC не используется для классификации, поэтому гуманоид не станет животным из-за
  совпадения части имени.
- Backend отклоняет неподходящий выбор до мутации персонажа и списания XP.
- Схема БД и seed не меняются; миграция не нужна.
- Проверки: backend 740 domain + 842 API; frontend 315 тестов, lint и production build.
- GitHub CI: backend, frontend, миграции на непустой БД и E2E smoke — успешно.
