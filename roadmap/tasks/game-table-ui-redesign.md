## Контекст

Новый локальный макет находится в пользовательском каталоге `UI макет игрового стола`. Нужно
перенести его визуальную структуру в существующий Game Table, сохранив работающие сценарии.
Нажатие на своего персонажа должно открывать его лист. Ведущий должен просматривать листы
персонажей игроков и статблоки NPC.

## Заметки / решения

- Каталог макета и zip остаются пользовательскими неотслеживаемыми файлами.
- Карточка собственного PC принудительно выбирает вкладку `sheet` перед переходом, поэтому
  сохранённая ранее вкладка персонажа не нарушает требуемый сценарий.
- Ведущий использует существующий защищённый endpoint и read-only окно листа участника;
  статблок NPC остаётся интерактивным окном игрового стола.
- Проверки: `npm run lint`; frontend Vitest (включая 11 целевых тестов); `npm run build`;
  `dotnet test backend/GenesysForge.slnx`; `git diff --check`.
- Известные предупреждения не связаны с задачей: NU1903 для `Microsoft.OpenApi 2.0.0` и
  предупреждение Rolldown о PURE-аннотации в `@microsoft/signalr`.
