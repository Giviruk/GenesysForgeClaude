# Тултипы свойств в эффектах заклинаний (spell-property-tooltips)

- **Пункт ТЗ:** пользовательский запрос — показывать описание свойства при наведении на его название внутри эффекта заклинания
- **Ветка:** `feature/spell-property-tooltips`
- **Базовая ветка:** `master` (после PR #203)
- **PR:** #не открыт
- **Статус:** 🚧 In progress

## Контекст

Описания дополнительных эффектов заклинаний уже содержат названия свойств («Взрыв», «Жжение», «Проникающее» и т. п.), но сейчас это обычный текст. Нужно сделать только такие названия интерактивными и показывать карточку с описанием свойства, не меняя текст и правила.

## Заметки / решения

- Assumption: интерактивность нужна в тексте описания эффекта, а не в строках копируемой карточки или `title` браузерных кнопок.
- Используем справочник `Reference.qualities`, передаваемый из листа персонажа; для мест без готового справочника сохраняем fallback на встроенные copyright-safe описания качеств.
