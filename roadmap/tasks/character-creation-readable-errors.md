- **Пункт ТЗ:** пользовательский запрос — понятные ошибки при завершении создания персонажа
- **Ветка:** `feature/character-creation-readable-errors`
- **Базовая ветка:** `master`
- **PR:** [#203](https://github.com/Giviruk/GenesysForgeClaude/pull/203)

## Контекст

Кнопка завершения создания персонажа отправляла запрос без обработки отказа. Ошибка могла попасть только в необработанное отклонение Promise, поэтому игрок не понимал, почему персонаж не завершён.
