## Заметки / решения

- Assumption: «страница обзора компании» — текущий dashboard кампании (`CampaignsPage`), а не список кампаний.
- Assumption: «текст везде» означает нормализацию локальных UI-типографических исключений, без изменения текстов/данных контента.
- Кнопка возврата навыка рендерится перед кубиком в DOM, но CSS-order оставляет кубик слева, а «−» в его прежнем action-слоте.
- Для пояснения о «Тёмном прозрении» добавлен вертикальный режим `.magic-rating.has-selector`: select и пояснение центрированы по одной оси.
- На обзоре кампании исходное выравнивание остальных блоков восстановлено; центрирование ограничено `.campaign-party-stats`.
