## Контекст

Выбранная вкладка листа персонажа хранится только в React state и сбрасывается на «Лист» после
ухода в другой раздел или обновления страницы. Серверное состояние игровой сцены сохраняется,
но локальный трекер дистанций теряет позиции и журнал при размонтировании.

## Заметки / решения

- Серверные данные сцены (участники, раны, инициатива, заметки) уже сохраняются backend и не меняются.
- Позиции дистанций и журнал остаются локальными для устройства, но больше не сбрасываются.
- Ключ трекера включает campaign id и session id, поэтому новая сцена не наследует старые позиции.
- Backend, API и схема БД не меняются; миграция не нужна.
- Проверки: frontend 324 теста, lint и production build.
