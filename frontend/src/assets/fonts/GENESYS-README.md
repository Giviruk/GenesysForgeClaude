This is a community font. The upstream README explicitly says it is not approved
by Fantasy Flight Games or Edge Studio. GenesysForge does not label it as an
official publisher font. The project uses its Genesys dice/result shapes in the
display layer; no book prose or embedded PDF fonts have been copied.

Font characters: success `s`, failure `f`, advantage `a`, threat `h`, triumph `t`,
despair `d`; solid square `j`, solid diamond `k`, solid hexagon `l`.
Hollow overprint glyphs have zero advance and are not used as standalone icons.
Only isolated glyph spans select the font. Ordinary text and numbers keep the
application's existing fonts, and accessible labels name every non-decorative icon.
