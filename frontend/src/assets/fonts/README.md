# Локальные шрифты

Cinzel (normal 600/700/800) и Spectral (normal 400/500/600/700; italic 400/500).
WOFF2 и исходные unicode ranges из официального Google Fonts CSS API;
общие файлы Cinzel переиспользуются. Получены 9 октября 2026 года.
В приложении все файлы обслуживаются с собственного домена.

Источники: [Cinzel](https://github.com/google/fonts/tree/main/ofl/cinzel),
[Spectral](https://github.com/google/fonts/tree/main/ofl/spectral).
Полные SIL OFL 1.1 сохранены в cinzel-OFL.txt и spectral-OFL.txt.
